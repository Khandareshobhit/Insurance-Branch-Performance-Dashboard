# Insurance-Branch-Performance-Dashboard
Interactive Insurance Branch Performance Dashboard built to analyze sales targets, revenue, invoice sales, achievement, opportunities, meetings, and account executive performance using data-driven visualizations.

## Project Problem Statement

The organization does not have a single dashboard to easily track and compare branch performance across **New, Cross-Sell, and Renewal** business.

The main challenges are:

* Data is stored in different **Excel sheets and CRM systems**.
* Difficult to compare **individual targets with actual achievements**.
* Limited tracking of **meetings, opportunities, and win ratios**.
* Difficult to monitor important **branch and individual KPIs**.
* Difficult to identify **top performers and areas that need improvement**.
* Reporting takes more time and can lead to **missed opportunities**.

The project aims to bring the data together using **Power BI, Tableau, and Excel** to make performance tracking easier, improve decision-making, and help branches achieve their targets.
